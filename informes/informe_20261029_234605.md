### 1. Diagnóstico y Mejoras de Arquitectura

1. **Fuga de recursos (Connection & Cursor Leaks):**
   * *Problema:* En el código actual ejecutas `cursor = conexion.cursor()` pero nunca se llama a `cursor.close()`. Con el tráfico continuo, el pool de MySQL o el proceso agota los descriptores y la memoria.
   * *Solución:* Usar bloques `try...finally` o context managers (`with`) para asegurar el cierre de cursores en cada petición.

2. **Conexión global propensa a desconexiones:**
   * *Problema:* Una sola conexión global estática fallará en cuanto MySQL alcance el tiempo de inactividad (`wait_timeout`) arrojando el error `MySQL server has gone away`.
   * *Solución:* Implementar una función de control de conexión con verificación activa (`conexion.ping(reconnect=True, attempts=3, delay=1)`).

3. **Inexistencia de manejo de excepciones por ruta:**
   * *Problema:* Si la base de datos se cae o una consulta falla, Flask arroja un error 500 no controlado al cliente.
   * *Solución:* Envolver las consultas en bloques `try/except` que muestren alertas visuales amigables de Bootstrap en lugar de romper la aplicación.

4. **Diseño del Módulo de Proveedores:**
   * Se integra un nuevo botón en el dashboard (`/`).
   * Se crea la ruta `/proveedores` asumiendo las columnas estándar de negocio para esta entidad: `cuit` (o código), `nombre` (o razón social), `telefono`, `email` y `direccion`.
   * Se añade una pantalla vacía amigable (*empty state*) si no hay registros.

### 2. Estructura de Base de Datos Recomendada

Si aún no tienes creada la tabla `proveedor` en MySQL, este es el script DDL estándar compatible:

```sql
CREATE TABLE IF NOT EXISTS proveedor (
    id INT AUTO_INCREMENT PRIMARY KEY,
    cuit VARCHAR(20) NOT NULL UNIQUE,
    nombre VARCHAR(150) NOT NULL,
    telefono VARCHAR(50),
    email VARCHAR(100),
    direccion VARCHAR(255)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

```python
DB_CONFIG = {
    "host": "localhost",
    "port": 3307,
    "user": "root",
    "password": "1234",
    "database": "ferreteria"
}

conexion = None

def get_db_connection():
    """
    Gestiona y mantiene activa la conexión a MySQL con reconexión automática.
    """
    global conexion
    try:
        if conexion is None or not conexion.is_connected():
            conexion = mysql.connector.connect(**DB_CONFIG)
            print("✅ Conexión establecida a MySQL")
        else:
            # Verifica si la conexión sigue viva y reconecta si cayó
            conexion.ping(reconnect=True, attempts=3, delay=1)
        return conexion
    except Error as e:
        print(f"❌ Error al conectar a la base de datos: {e}")
        return None
```
